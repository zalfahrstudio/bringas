# BRINGAS — Atomic Habits

Dibuat dengan menggunakan `BRINGAS-Let-Them-Theory-Template.zip` sebagai template desain dan struktur artikel satu buku per halaman.

## File
- `index.html` — artikel Atomic Habits, ringkasan tanpa spoiler, prinsip inti, contoh sehari-hari, 10 contoh kebiasaan sehari-hari, kutipan editorial orisinal, workbook 7 hari, CTA affiliate, metadata SEO.
- `style.css` — gaya template yang diadaptasi ke aksen hijau-sage dan terracotta, responsif dan mendukung mode terang/gelap.
- `script.js` — reading progress, tema, menu mobile, checklist interaktif, salin pertanyaan refleksi, dan CTA affiliate.
- `assets/atomic-habits-hero.jpg` — ilustrasi hero.
- `assets/habit-editorial-detail.jpg` — ilustrasi editorial di dalam artikel.
- `assets/bringas-icon.png` — ikon BRINGAS.

## Preview lokal
Buka `index.html` di browser. Disarankan memakai Live Server untuk pengujian.

## GitHub Pages
1. Unggah seluruh isi folder ini ke root repository.
2. Aktifkan Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
3. Ganti `USERNAME` pada canonical, Open Graph, dan JSON-LD di `index.html`.
4. Ganti placeholder affiliate pada `index.html` dan `script.js` dengan tautan produk affiliate yang valid.
5. Pastikan produk/edisi sesuai dan ikuti kebijakan program affiliate.

## Catatan
Contoh sehari-hari adalah ilustrasi editorial BRINGAS, bukan kasus nyata atau hasil penelitian. Artikel ini merupakan ringkasan interpretatif dan analisis orisinal, bukan pengganti buku asli. Mockup buku bersifat generik dan bukan reproduksi sampul resmi.


## Perbaikan hero dan sampul
- Hero memakai `assets/atomic-habits-hero.jpg`; CSS tidak lagi menunjuk ke file `let-them-hero.png` yang tidak ada.
- Mockup buku pada hero dan CTA memakai `assets/atomic-habits-cover.svg`, visualisasi editorial yang mengikuti komposisi sampul edisi Inggris (krem, judul bertitik emas, subtitle, segel oranye, nama James Clear). Ini bukan foto produk resmi.
- Pastikan tautan affiliate mengarah ke edisi yang cocok dengan gambar produk.


## Revisi bahasa dan contoh
- Bahasa dibuat lebih santai, komunikatif, dan mudah dipahami tanpa mengubah inti gagasan buku.
- Label pergeseran fokus dibuat lebih hidup dengan panel visual yang lebih menonjol.
- Bagian studi kasus startup diganti menjadi 10 contoh kebiasaan sehari-hari: belajar, melatih skill, membaca, olahraga, mengurangi scrolling, rutinitas pagi, menabung, belajar bahasa, kerja, dan membuat konten.
- Contoh dibuat ringkas agar pembaca bisa langsung menangkap masalah, cara mencoba, dan intinya.
